# fastest-name-tracker

Open `index.html` in a browser. Type one name per line and press Enter to add the next; names are numbered automatically, and you can edit them with the mouse, touchpad, or arrow keys. The first letter of each word is capitalized without autocorrect.

The header shows character, word, and name counts. Use the theme button to switch between light and dark mode. The **Sort** menu orders names by first name, last name, or full name alphabetically or by length, and can reverse the current order. **Clean up** removes repeated first-and-last-name pairs (ignoring capitalization and extra spaces) while keeping the first entry.

Open **Tools** for undo/redo (also available with Ctrl/Cmd+Z), find and highlight, a random name picker, list statistics, and drag-and-drop or button-based reordering. Your list and theme are saved in the browser; **Download** exports a numbered text list, while **Backup** downloads a restorable JSON file and **Restore** loads one.
